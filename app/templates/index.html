Настройки ответа с ограничениями

{
  "type": "json_object"
}

Фиксировано для контролируемого запроса.

Что делает: это реальный API-параметр response_format, который передаётся в DeepSeek и включает режим JSON-объекта (JSON Output).
Механизм API: response_format={"type": "json_object"}.
Важно: этот параметр сам по себе не задаёт поля вроде name/count/unit. Поля определяются отдельно — через «Требуемую структуру JSON-ответа», которая передаётся как инструкция в messages.
Требование DeepSeek: в messages должно встречаться слово «json» — наша инструкция это обеспечивает.
Что делает: задаёт желаемую структуру (поля) JSON-ответа. Меняйте её на лету, например products → ingredients или добавляйте поля.
Механизм: это инструкция в messages, а не API-параметр. Само «принуждение» к JSON выполняет response_format; структура лишь описывает, какие ключи ждать.
Эффект: модель наполняет переданную структуру реальными данными из запроса.
Ограничения: корень должен быть JSON-объектом, не пустым. Некорректный JSON отклоняется до платного вызова API.
токенов
Что делает: ограничивает число токенов, которые модель может сгенерировать.
Механизм API: передаётся как параметр max_tokens, например max_tokens=300.
Важно: токен — не буква и не слово. Модель может закончить и раньше. Если лимит исчерпан, finish_reason может стать "length", а ответ оборваться.
JSON Output: если лимит слишком мал для полного JSON, DeepSeek может завершить генерацию с finish_reason='length'. Для режима JSON Output провайдер иногда возвращает пустой content вместо обрезанного JSON — тогда поднимите максимальную длину ответа и нажмите «Сравнить ответы» снова.
Это управление генерацией на стороне API, а не визуальная обрезка текста.

Необязательно. Может преждевременно прервать JSON-ответ.

Что делает: стоп-последовательность — маркер, при появлении которого генерация прекращается.
Механизм API: передаётся как параметр stop, например stop=["END_OF_RESPONSE"].
Эффект: достигнув маркера, API останавливает вывод; сам маркер обычно не попадает в ответ.
Отличие от max_tokens: max_tokens — «не больше N токенов»; stop — «заверши генерацию при появлении маркера».
Образовательная оговорка: для обычного JSON вывода стоп-маркер в реальной разработке часто не нужен; здесь он показан намеренно, чтобы продемонстрировать управление завершением через API. Модель должна «решить» выдать маркер. Используйте различимый длинный маркер (минимум 4 символа, с буквой/цифрой) — короткий или частый маркер (например «}» или отдельное слово) может совпасть с текстом JSON, оборвать генерацию внутри JSON и дать пустой/незавершённый ответ.

Параметры контролируемого API-запроса

{
  "response_format": {
    "type": "json_object"
  },
  "max_tokens": 500
}

response_format = API-уровень JSON-режима · max_tokens = лимит длины · stop = маркер завершения.
