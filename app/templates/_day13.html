День 13 — Состояние задачи (Task State Machine)

Задача существует как структурированное состояние (stage, current_step, expected_action), а не как текст внутри истории диалога. Допустимые переходы между стадиями контролируются кодом: LLM не может произвольно установить stage. 

planning ──► execution ──► validation ──► done
                 ▲              │
                 └──────────────┘   validation → execution
                                   (если проверка не пройдена)
