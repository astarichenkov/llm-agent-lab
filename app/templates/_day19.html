Day 19 — MCP Pipeline

Три MCP-инструмента объединяются в автоматический pipeline: search_logs получает данные, analyze_logs делает структурированный анализ (LLM), save_report детерминированно сохраняет артефакты. Backend сам выполняет шаги в правильном порядке и передаёт результат каждого tool следующему — пользователь не указывает порядок вручную.

Run pipeline
