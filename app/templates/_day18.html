Day 18 — Scheduled Monitoring

Пользователь (или агент через MCP) создаёт monitoring job для stage-логов VictoriaLogs. Долгоживущий scheduler в приложении периодически выполняет детерминированный сбор данных (без LLM), результаты-агрегаты сохраняются в SQLite, а дашборд показывает историю запусков и сводку.

Agent request (monitoring MCP tools)

LLM видит только Day 18 monitoring-tools и сам выбирает start_monitoring / get_monitoring_summary / stop_monitoring; backend выполняет настоящий MCP tools/call.
